音频设备

选用虚拟声卡的播放端，例如 CABLE Input。下次开启会议英文语音时生效。

用 VB-CABLE 将英文送进 Teams / Zoom 等会议
  1. 在 Windows 安装 VB-CABLE。
  2. 译桥的麦克风选实体麦克风，会议英文输出选 CABLE Input。
  3. 会议软件的麦克风选 CABLE Output，扬声器选 Windows 默认耳机。
  4. 回到译桥，接入会议音频并开启「实时说话转英文」。用会议软件的麦克风测试确认收到了英文。

Windows 桌面版会采集默认播放设备的声音，其中可能包括其他应用和通知。
